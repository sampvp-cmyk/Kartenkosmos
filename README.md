# 🪐 Kartenkosmos

Eine Web-App mit Startmenü für Kartenspiel-Helfer – weitere Spiele kommen als neue „Planeten“ dazu:

- **Wizard Block** (`wizard/`) – Punkteblock für Wizard mit allen Editionen, Einstellungen, Geber-Auswahl, Zwei-Decks-Modus
- **Kniffel Block** (`kniffel/`) – Punkteblock mit Würfeln, Kopie aus [Kniffel-Block](https://github.com/sampvp-cmyk/Kniffel-Block)
- **Werwolf** (`werwolf/`) – Spielleiter-Helfer für beliebig viele Spieler: Karten reihum ansehen, geführte Nacht, Abstimmung, Siegprüfung – mit 30 Rollen aus Grundspiel, Neumond, Charaktere und weiteren Varianten (u. a. Urwolf, Weißer Werwolf, Flötenspieler, Engel, Fuchs, Bärenführer, Dorfältester, Hauptmann)
- **Arschmallows** (`arschmallows/`) – Merk-Helfer, Kopie aus [Arschmellow-2.0](https://github.com/sampvp-cmyk/Arschmellow-2.0)

Hell/Dunkel: im Startmenü oben links unter ⚙️ Einstellungen (Auto folgt der iPhone-Einstellung) – gilt für alle Apps.

Live: https://sampvp-cmyk.github.io/Kartenkosmos/ – in Safari „Teilen → Zum Home-Bildschirm“.
