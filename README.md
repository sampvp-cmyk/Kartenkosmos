# Wizard Block 2.0

Punkteblock für das Kartenspiel **Wizard** als Web-App (eine `index.html`, React über CDN).

- Spieler anlegen (3–6), Regel wählen (Standard, Aufgehen, Plus/Minus, geheim …)
- Alle Editionen: Standard, Jubiläumsedition (20 Jahre), 25-Jahre- und 30-Jahre-Edition (Bombe 💣 und Wolke ☁️)
- Pro Runde Trumpf, Ansagen und Stiche eintragen, Punkte werden automatisch berechnet
  (Treffer: 20 + 10 pro Stich, daneben: −10 pro Stich Abweichung)
- Rangliste und klassischer Punkteblock, Spielstand bleibt im Browser gespeichert

Kopie von [Wizard-Block](https://github.com/sampvp-cmyk/Wizard-Block) mit eigenem Speicher.

Live: https://sampvp-cmyk.github.io/Wizard-Block-2.0/
